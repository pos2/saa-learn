# 阶段 5：知识点与高级检索

本阶段把解析产生的知识点从题目详情中的附属内容，提升为可以独立浏览和检索的学习资料。

## 已实现

- 独立知识点入口、列表页和详情页
- 知识点名称、讲解、考试线索及关联题目数量
- 从知识点详情跳转到关联题目
- 题库与知识点列表均支持数据库分页和“加载更多”
- 多关键词检索；不同关键词之间采用 AND 语义
- AWS 常用术语的中英文别名扩展
- 题库结果按照标题、标签、知识点、摘要、原题的字段权重排序
- 搜索结果中的原始输入词高亮

## 当前检索策略

当前使用数据库侧的归一化文本匹配和相关度计算，不依赖浏览器内存过滤。这样可以在本地 D1 / SQLite 环境中直接工作，也不需要新增索引迁移。

当题库增长到数千或数万条、并需要词干化或更复杂的短语查询时，可以把检索实现替换为 D1 FTS5；现有 API、分页参数和前端交互无需改变。

## 暂不包含

- 用户选择答案和提交判分
- 搜索历史与保存的筛选条件
- 知识点人工合并、拆分和别名管理界面

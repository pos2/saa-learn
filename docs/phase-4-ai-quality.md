# 阶段 4：AI 解析质量与可控性

阶段 4 已在本地完成，目标是让模型输出从“能展示”升级为“可校正、可追踪、可重跑”。

## 已实现

- DeepSeek V4 Flash 生成中文解析，英文原题原样保留。
- 解析前后防重复提交；已保存题目支持重新解析并覆盖原记录。
- 对 HTTP 429、500、503 以及网络/超时类瞬时错误自动重试一次；认证、余额和参数错误不重试。
- 保存前允许编辑答案、结论、服务、候选题型、关键词、逐项解释及知识点。
- 服务端严格校验原题选项是否全部覆盖、答案是否与正确选项标记一致、解释是否为中文。
- 每次运行持久化模型、系统 Prompt 快照、原始响应、输入/输出/推理/总 token、尝试次数和耗时。
- 模型调用失败时保留题目输入和已有解析，不写入题库。

## 本地验收路径

1. 在“题目解析”粘贴英文题目并开始解析。
2. 确认页面显示模型、token、尝试次数和耗时。
3. 点击“编辑解析”，修改内容后保存。
4. 在“我的题库”找到题目，修改掌握状态。
5. 点击“重新解析此题”，确认成功后保存，题库数量不应增加。
6. 将答案改成与正确选项勾选不一致的值，保存应被阻止并显示错误。

# 阶段 3：中文解析与掌握状态

## 解析流程

1. 浏览器将英文原题发送到本地 `/api/analyze`。
2. 服务端读取数据库中的自定义系统 Prompt。
3. 服务端调用 `deepseek-v4-flash` 的 Chat Completions API，并启用 JSON Output。
4. 应用校验返回字段、选项解释、知识点以及中文内容。
5. 解析预览保留英文原题，所有解释性内容使用简体中文。
6. 用户确认保存后，将解析运行记录关联到题目。

系统 Prompt 可以自定义，但应用始终追加两项不可省略的输出契约：英文原题不改写、解析使用简体中文和固定 JSON 结构。

## 掌握状态

- `unreviewed`：未复习，新保存题目的默认状态。
- `learning`：学习中。
- `mastered`：已掌握。

状态存储在 `questions.mastery`，支持在题目详情中修改，并在题库页筛选。当前不包含用户笔记。

## 本地配置

将 `.env.example` 复制为 `.env.local`，设置 `DEEPSEEK_API_KEY` 后重新启动本地服务。没有密钥时解析接口返回明确错误，不会退回模拟答案。
